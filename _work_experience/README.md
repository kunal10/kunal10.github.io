# Work Experience Entries

This directory contains your work experience entries. Each entry should be a Markdown file with the following front matter:

```yaml
---
layout: post
date: YYYY-MM-DD 00:00:00-0400
inline: true
related_posts: false
---

**Job Title, Company**
*Month YYYY - Present*
Description of your role and responsibilities. You can use Markdown formatting here.
```

## Adding a New Work Experience Entry

1. Create a new Markdown file in this directory with a descriptive name (e.g., `google_ai.md`)
2. Add the front matter as shown above
3. Add your work experience details in the content section
4. Save the file with a `.md` extension

## Example

```markdown
---
layout: post
date: 2022-02-01 00:00:00-0400
inline: true
related_posts: false
---

**Senior Software Engineer, Google AI**  
_February 2022 - Present_  
Working on Generative AI models for Education & Learning to enable transformative educational experiences across Google surfaces like Gemini, Search, YouTube, Google Classroom, NotebookLM, and GCloud.
```
